# v0.1.12

Ticket Multi-Summon now uses the number of tickets shown on the button and awards the matching number of units. Every guaranteed ticket keeps its rarity guarantee when used in a batch.

This update also includes the shop-ticket fixes from v0.1.11: Rare tickets work on eligible single-summon banners, and NV EX tickets work on NV EXVIUS Summon.

Install over your existing app. Your save, purchased tickets and downloaded game data stay in place.
