# Exvius Offline v0.1.15

- Eligible Neo Vision units can be selected for fragment conversion and give their corresponding rewards. Game data update 5 supplies the fragment table to existing installs.
- Cactuars bought from the shop add EXP you can spend on unit enhancement.
- Equipment stays equipped when you enter battle.
- Rain can walk after arriving in the Town of Mitra. The launcher delivers this fix through game data update 4.

If you already play Exvius Offline, open the game and accept the Android update when prompted. Your campaign and downloaded game data carry over.
